# 概述

openEuler-26.09-DevStation是openEuler的智能开发者工作站版本，主要为开发者提供开箱即用、集成AI能力、高效安全的开发环境，无需复杂配置，即可体验智能化操作系统交互进行openEuler相关的开发工作。

本文主要描述openEuler 26.09 DevStation 版本的总体测试策略，按照社区开发模式进行运作，结合社区release-manager团队制定的版本计划规划相应的测试活动。整体测试策略覆盖新需求、继承需求的测试分析和执行，明确各个测试周期的测试策略及出入口标准，指导后续测试活动。

## 版本背景

openEuler 26.09 DevStation基于6.18新内核，围绕智能化一站式开发环境，主要功能包括：
1) 支持开发者友好的图形化编程环境，支持多种编程语言，vim、gcc、gdb、gnome、vscode等支持开箱即用，默认安装
2) DevStation智能助手，支持通过问答、智能shell等交互方式进行开发和运维
3) 支持社区原生开发工具链，如一键式部署工具oeDeploy，可在DevStation上快速部署相关环境
4) 支持开发者软件商店，提供常用软件、服务的一键式获取
5) 支持PC清单：thinkbook E16；华硕天选4 锐龙版；惠普Book Pro 14 锐龙版
6) 支持服务器型号：920、920新型号
7) Gnome相关组件软件包升级至49版本，保持与上游社区稳定版本同步
8) 内核升级至6.18，保持与上游社区稳定版本同步
9) nodejs升级至22版本，符合openclaw等agent最低的部署运行要求
10) 集成智能问答工具polymind，支持开发者通过问答的方式获取相关信息
11) 支持epkg包管理工具，可在DevStation上方便地安装、升级、删除软件包

## 专项测试策略

### 安全测试

DevStation作为社区开源创新版本，在系统整体安全上需要进行保证，以发现系统中存在的安全脆弱性与风险，为版本的安全提供切实的依据，推动产品完成安全问题整改，提高产品的安全。整体安全测试需要覆盖：

1.  Linux系统安全配置管理类测试

2.  安全编译选项测试

3.  无密码、弱密码登录桌面测试

| 测试类 | 描述 | 具体测试内容 |
| -------- | -------- | -------- |
| 安全扫描类 | 桌面登录安全扫描 | 针对桌面登录场景，验证系统是否存在无密码登录、弱密码登录等安全风险；编译选项和敏感信息需要针对新开源特性及新增软件包进行 |
| 安全配置管理类 | Linux安全规范 | Linux安全规范包括：调试工具检查、冗余文件检查、无属主或无属组文件检查、预置账号信息检查、证书文件合规性检查等；需对DevStation进行上述安全配置测试 |

### 可靠性测试

可靠性是版本测试中需重点考虑的测试活动，在各类资源异常/抢占竞争/压力/故障等背景下，通过功能的并发、反复操作进行长时间的测试；过程中通过监控系统资源、进程运行等状态，及时发现系统/特性隐藏的问题。

可靠性的测试建议从关键特性、重要组件、新增特性的可靠性指标和系统级的可靠性进行分析和设计，以保证特性和系统在各类异常、故障及压力背景下的持续提供服务的能力。

| 测试类型 | 具体测试内容 |
| -------- | -------- |
| 操作系统长稳 | 系统在各种压力背景下，通过构造资源类和服务类等异常，随机执行LTP、系统管理操作等测试；过程中关注系统重要进程/服务，日志等异常情况；建议稳定性测试时长7\*24 |
| 操作系统重启 | 系统连续重启100次，查看启动日志无报错；断电重启连续10次测试，查看启动日志无报错 |
| 桌面稳定性 | 在长时间使用过程中，验证桌面环境、智能助手、软件商店等关键组件的稳定性与资源占用情况 |

# 测试执行策略

openEuler 26.09 DevStation版本按照社区release-manager团队既定的版本计划，共有4轮测试，按照社区研发模式，所有的需求都在拉分支前已完成合入，因此版本测试采取2+1+1的测试方式，即2轮基本功能保障发布beta版本可以提供给外部开发者，1轮全量保障本次版本发布所有特性(新增&继承)以及系统其他dfx能力，1轮回归。

### 测试计划

openEuler 26.09 DevStation版本按照社区开发模式进行运作，结合社区release-manager团队制定的版本计划规划相应的测试活动。

测试阶段1：

1.  继承特性/新特性的基本功能

2.  系统集成方面保证多组件多模块集成的正确性和整体系统的完整性

3.  专项情况如下：

    兼容性测试：PC清单（thinkbook E16；华硕天选4 锐龙版；惠普Book Pro 14 锐龙版）及服务器型号（920、920新型号）硬件测试

1.  专项：

    可靠性：保证版本的长时间稳定运行，建议运行时长7\*24

    性能：保证版本的性能满足发布基线标准

    安全测试：进行安全编译选项、敏感信息扫描、无密码及弱密码登录桌面测试

1.  DevStation新增特性（Gnome 49、内核6.18、nodejs 22、polymind、epkg）基础功能验证

2.  桌面系统测试基线全量验证

1.  交付特性/组件的全量测试

2.  专项：文档测试

3.  问题单回归

4.  系统集成验证

### 入口标准

1.  上个阶段无block问题遗留

2.  转测版本的冒烟无阻塞性问题

### 出口标准

1.  策略规划的测试活动涉及测试用例100%执行完毕

2.  发布特性/新需求/性能基线等满足版本规划目标

3.  版本无block问题遗留，其它严重问题要有相应规避措施或说明
