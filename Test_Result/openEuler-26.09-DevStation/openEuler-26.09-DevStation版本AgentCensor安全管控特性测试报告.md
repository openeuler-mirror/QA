# 1     特性概述

CensorGuard（仓库 openeuler/AgentCensor 子项目）是面向 Agent 运行时的安全管控与审计系统。系统基于 eBPF LSM 内核技术，对 Agent 进程的文件访问、程序执行、网络连接进行系统级实时管控，命中拒绝策略时直接拦截，使 Agent 的运行行为始终处于既定策略边界之内；同时，管控过程中的每一次拦截与放行都会生成审计事件并实时上报，事件可按需订阅，及时掌握 Agent 的行为轨迹与越权尝试。

系统由三部分组成：

* **内核管控层**：基于 eBPF LSM 技术，在内核层对进程的文件、执行、网络行为进行实时判定与拦截，策略变更无需重启即可生效；
* **用户态服务**：`censorguardd` 守护进程负责策略管理与热更新、Agent 进程树追踪、审计事件的汇聚与分发，并配套命令行管理工具与审计事件订阅工具；
* **AI Agent 侧集成**：DSH 插件（`@censorguard/dsh`）将 DSH Agent 运行环境整体纳入管控，并提供安全策略配置与审计事件展示能力。

本次测试重点验证以下特性：

* 文件访问管控：基础拦截、拒绝优先、权限掩码、目录继承、写映射提权拦截；
* 执行管控：命令级与参数级拦截、exec 防绕过、多执行域隔离、无竞态纳管；
* 网络管控：IPv4/IPv6 地址与域名维度的连接管控；
* 策略管理：策略热更新、非法配置自动回滚、绑定解绑、运行时开关；
* 进程纳管：进程树血统追踪、PID 复用防护、运行中进程 attach/untrack；
* 运行保障：守护进程基础门禁、退出、x86_64/aarch64 构建；
* 审计事件上报：管控事件实时上报，放行事件按开关受控；
* 事件订阅过滤：支持按事件类别与进程维度过滤订阅；
* Agent 侧集成：DSH 插件安装 attach 与自检验收全链路可用。

## 3.2   约束说明

* 本次测试基于开启 BPF LSM 与 BTF 的 Linux 内核环境开展，不覆盖未开启 BPF LSM 的内核（该场景下 daemon 无法加载数据面，属设计约束）。
* 集成类用例需 root 权限执行；socket 父目录必须 root 所有且非 group/other 可写，不得置于 /tmp。
* 全部 LSM hook（文件/exec/网络）拒绝时统一返回 -EPERM（errno=1，"Operation not permitted"），测试断言均以 EPERM 为准，不使用 EACCES。
* fail-open 仅允许出现在显式设计点：enable 开关关闭、DSH blockOnFailure=false 降级；任何其他位置的误判放行均判定为阻断级缺陷。
* DSH 插件测试依赖 DSH 运行时环境，自检验收在插件验收环境中执行。
