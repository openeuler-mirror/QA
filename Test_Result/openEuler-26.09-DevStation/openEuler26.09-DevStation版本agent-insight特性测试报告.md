# 1     特性概述

Agent Insight 是openEuler社区孵化的开源AgentOps平台，致力于构建「观测 → 评测 → 诊断 → 优化」持续运转的能力闭环，以及贯穿全流程的可靠性保障能力，将黑盒化的Agent转化为可观测、可度量、可治理的可信资产，使生产级Agent做到"行为看得清、故障诊得准、服务跑得稳"，并持续进化。

本报告为Agent Insight管理平台 openEuler 26.09版本新增特性的整体特性验收测试报告，覆盖四个功能模块：

**功能模块一：安装部署**。完成Agent Insight平台客户端及服务端的安装部署验证，包括环境检查（Node.js ≥ 20）、目录结构检查、安装脚本执行及易用性验证。

**功能模块二：链路追踪**。覆盖前端界面的全链路追踪功能，包括页面登录、文本搜索、结构化过滤、高级过滤器、表头列宽调整、Trace导入导出、链路树展示、详情页、时间线等核心功能。本次仅转测前端界面功能，后端 REST API 接口实现与参数校验不在本次范围。

**功能模块三：模型注册（模型配置管理）**。整体上解决"平台如何配置并安全维护调用大模型的连接"。流程：从预设服务商模板（DeepSeek、SiliconFlow、OpenAI、Anthropic 等点击即进入创建表单）或 OpenAI 兼容自定义入口注册连接配置 → 填写模型信息与 API Key（可附加自定义请求头）→ **保存前先执行连通性测试**，测试通过才落库，失败则保留表单并展示错误 → 配置以卡片展示与编排，可编辑、设为当前默认、删除。安全性贯穿整体：**API Key 全程掩码**（页面与接口响应均不出现明文 sk-，掩码值可直接重测）；配置卡显示连接状态标识（实机可见「正常」「当前默认」）。

**功能模块四：评测功能（评测管理）**。整体上解决"对 Agent 运行产生的 Trace 组织评测并输出得分"。运作流程：①**采集**——从链路追踪页将 trace 加入评测集（亦可新建评测集 / 本地导入）；②**组织**——在评测集中维护数据项（字段管理、单个/批量添加、JSON 字段展示、长轨迹编辑删除），编辑保存保持内容无损、重复保存幂等不膨胀；③**评估**——为实验选用评估器（平台预置 6 个 / 自定义，可刷新加载）完成打分，监听模式的实验可不预选 case，自动纳入所选 Agent 新上报 Trace；④**呈现**——实验详情页展示评估器分解得分与综合均分，综合均分仅计入评估成功且有分的评估器。

## 3.2   约束说明

本次验收依据相关设计规格的约束要求执行，主要约束如下：

1. **安装部署**：客户端需 Node.js ≥ 20，版本不足时安装脚本停止执行。
2. **链路追踪**：本次仅转测前端界面功能，后端 REST API 接口实现与参数校验不在本次范围；RAS、评测集、打标签、智能诊断、评测跳转、列表复选框等模块不属于本次转测范围，不验收。
3. **链路追踪**：慢节点判定为节点耗时严格大于 60 秒（等于 60 秒不算）；导入文件仅接受 Trace Bundle JSON 且超过 50MB 提示不发起导入。
4. **保存门禁**：模型注册页面保存前先执行连通性测试，单次最多等待 10 秒（请求内容 Hi、最大输出 5 Token）；直接调用保存接口时服务端不校验是否已测试，页面流程与接口流程需分别覆盖。
5. **容量与分页**：模型注册页面显示 32 份配置容量提示，服务端无 32 条硬限制（配置一次全量读取不分页）；评测功能数据集列表当前不分页（可用 `summary`/`reference` 视图减载荷），实验/详情/Trace 分页默认 20、最大 100。
6. **敏感字段**：API Key 与自定义请求头值在页面及接口响应中一律使用掩码，数据库仍保存明文；掩码值可直接重测，服务端按 user+configId 恢复真实密钥。自定义请求头仅 Custom 模型可配置，服务端拒绝连接级请求头、原型污染键、非法名称、CR/LF 与重复键。
7. **评测·数据集**：名称页面限制 50 字符、描述页面上限 200 字符；导入仅支持 `.json`/`.csv`；列表按更新时间倒序；关键点提取仅在参考输出非空且发生变化时调用模型，失败仅告警不阻断数据保存。
8. **评测·实验限制**：创建向导跨页全选 Trace 最多 500 条为页面选择上限（创建接口本身无对应数量硬限制）；向既有实验追加 Case 单次硬限制 200 条（超限整批拒绝、无部分写入）；结果行级并发上限 4；单次评估尝试超时 5 分钟（每次尝试，非整行总时限），可重试错误最多 3 次尝试（间隔 2s/8s）；人工评分 0~100、理由超 1000 字符截断；评论正文超 2000 字符截断、单次查询最多返回 500 条。
9. **部署与运行约束**：关键点提取与 LLM 评估依赖可用模型服务；实验引擎为每次结果行尝试设置 5 分钟外层超时；后台 OpenCode 并发上限 5；多实例部署时进程内锁与行级并发按实例生效；服务重启不自动恢复内存中的实验调度任务。
10. **DFX专项测试边界**：安全测试与可靠性测试中发现的API层问题（未授权访问、路由守卫、输入校验等）经与开发团队对齐，均不在本次前端转测范畴内，后续版本规划解决；本次DFX仅验收前端体验相关的性能与韧性指标。
11. 特性需保证在openEuler社区范围内依赖自闭环；反之需在TC、RM获取例外结论后，提供完整的二进制依赖，保证所有依赖公开可获得。
