# 1     特性概述

epkg是一个绿色轻量的跨平台包管理器，支持 Linux、macOS 和 Windows。创建隔离的 environments，安装使用常见发行版（RPM、DEB、Alpine、Arch、Conda、Homebrew、MSYS2）的软件包，无需 root 权限。每个环境绑定到一个 channel（如 Debian、Fedora、Alpine 等指定版本）。注册多个环境，将其二进制文件组合到 PATH 中，在一个 shell 中混合使用不同发行版的软件。

本次测试重点验证以下特性：

* 支持 `env` 和 `fs` 两种软件运行隔离模式；
* 支持不同发行版软件包的安装、运行和环境隔离；
* 验证 Ubuntu、Fedora 等发行版软件包在openEuler DevStation上的部署能力；
* 验证epkg默认集成至DevStation后的开箱即用能力；
* 验证环境创建完成后软件安装及拉起效率，软件安装拉起时长要求小于1s。

# 3     测试结论概述

## 3.1   测试整体结论

本次测试共执行49个测试用例，主要覆盖功能测试、兼容性测试及性能测试。其中49个用例通过，0个用例未通过，发现两个问题单，问题分别对应epkg Issue #80和Issue #81。两个问题均已完成修复，并完成回归验证。

功能测试重点验证`env`、`fs`两种隔离模式以及Ubuntu、Fedora等不同发行版软件包的部署和运行；集成测试验证epkg默认集成至openEuler DevStation后能够直接使用；性能测试验证环境创建完成后软件安装及拉起时长满足小于1s的要求。

env模式是基于namespace + bind mount将/usr、/etc、/var、/run覆盖到相应位置，共用宿主内核，适合日常开发。
fs模式是pivot_root进入环境根，其下挂载。隔离能力稍强于env模式，需要完整文件系统视图的构建与测试。

整体测试结果表明，epkg主要功能运行正常，多发行版软件包部署能力满足预期，环境隔离功能可用，软件安装及运行效率满足当前测试指标。遗留问题已完成修复，当前无已知遗留风险，整体特性质量良好。
