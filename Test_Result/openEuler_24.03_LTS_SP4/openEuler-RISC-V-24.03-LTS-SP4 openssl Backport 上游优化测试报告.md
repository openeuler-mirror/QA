# 1     特性概述

openEuler RISC-V 24.03 LTS SP4 中的 openssl 基线版本为 3.5.6 ，而当前 openssl 的最新版本已经到了 3.6 系列。与openssl 最新版本相比，3.5.6 版本缺少许多针对 RISC-V 的汇编支持及性能优化，将上游主线版本中已合并的部分密码学汇编优化算法 Backport 到 3.5.6 中，可以进一步优化 openEuler RISC-V 24.03 LTS SP4 下 openssl 在 RISC-V 下的性能表现。

# 3     测试结论概述

## 3.1   测试整体结论

环境变量 `OPENSSL_riscvcap` 设置为 `rv64gc_zbb`，强制启用 RISC-V 64 下的 Zbb 优化，执行 openssl 编译过程自带的 make test 测试，2890 个测试案例可以通过

| 性能专项测试 | 测试通过 |

## 3.2   约束说明

1. Linux 内核需要大于 6.6 方支持 RISC-V hwprobe 特性（openEuler 已支持）

2. RISC-V CPU 需要支持 Zbb 拓展才可以使用 SHA-2 Zbb 汇编优化 

3. RISC-V CPU 需要支持 Zbb 拓展才可以使用 MD5 Zbb 汇编优化 

4. 若不满足条件则只使用普通汇编优化，不影响功能使用
